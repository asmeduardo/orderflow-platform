# Contribuição

1. Abra uma issue que descreva o problema e o critério de aceite.
2. Crie uma branch curta a partir de `main`.
3. Entregue código, testes e documentação na mesma alteração.
4. Execute o gate local documentado no README antes de abrir o pull request.
5. Explique decisões, riscos e evidências de verificação no pull request.

Commits devem registrar uma mudança coerente. Segredos, arquivos gerados e configurações pessoais não pertencem ao repositório.
